## Core Mechanics and Rules of the BloxNote Notebook

The central gameplay loop of BloxNote revolves around the acquisition and execution phases of the item. When a player obtains the item, they receive an interactive user interface resembling a leather-bound journal where names, conditions, and timings can be inscribed.

Unlike simple click-to-attack weapons found across standard action titles on the [official Roblox platform](https://www.roblox.com), this item requires precision input. Misspelling a target's username or failing to fulfill prerequisite conditions will invalidate the entry, wasting valuable time and exposing your role.

### The Basic Rules of Inscription

To trigger an elimination successfully, the user must satisfy several mechanical conditions within the engine:

| Requirement Parameter | Engine Condition | Failure Result |
| :--- | :--- | :--- |
| **Target Name** | Exact Display Name or Unique Handle | Null action; timer resets |
| **Visual Line-of-Sight** | Direct gaze or recent visual confirmation | Inscription fails to register |
| **Face Memory Buffer** | Must have rendered target's avatar within 45s | Red ink warning; no trigger |
| **Cause of Death** | Specified within 6.5-second sub-window | Defaults to standard heart failure |
| **Environmental Context** | Plausible physical physics within the map | Target defaults to standard failure |

If a player attempts to eliminate a target whose face has not been registered by their avatar's field-of-view camera, the notebook will reject the entry. This visual buffer mechanic prevents spawn-room sweeps and forces the writer to roam actively.

## Frequently Asked Questions (FAQ)

### Can the BloxNote notebook eliminate multiple players at once?
No. Standard game balance restricts the item to one name per inscription cycle. After submitting an entry, the writer must wait through the standard cooldown (typically 60 seconds) before opening the interface to inscribe another target.

### What happens if you misspell a player's name in the BloxNote notebook?
Entering an incorrect username triggers an automatic Misspell Penalty. The book locks for 15 seconds, during which no names can be typed, and your avatar emits a subtle audio-visual cue that nearby investigators can detect.

### Can detectives steal or destroy the BloxNote notebook?
Detectives cannot directly destroy the item from inventory, but securing a successful arrest or search on the holder will confiscate the journal, immediately securing a victory for the investigative team.

### Does changing avatar appearance mid-round protect against the notebook?
Based on player experience across competitive servers, cosmetic changes or accessory swaps do not clear the face memory buffer once an opponent has established line-of-sight during the active memory window.
